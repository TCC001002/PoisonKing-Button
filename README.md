# PoisonKing 按键辅助 v1.0

<img src="src/banner.jpg" width="100%" alt="PoisonKing 按键辅助">

> 多窗口独立按键方案 + 后台连发 · Windows 单文件绿色工具 · 基于 .NET Framework 4.x（WinForms）

每个窗口一套独立的按键方案（各自的热键、各自的多组连发绑定），双开 / 多开时切到别的窗口，连发也不会中断。**不修改游戏文件、不读取游戏内存、不注入 DLL**，只向目标窗口发送标准键盘消息。

单文件绿色版：不写注册表、不装服务、不联网、不上传任何数据，拷贝到 Win10 / Win11 双击即用。

---

## 功能特性

**多窗口独立方案**

- 窗口列表按 PID + 进程名识别，每个窗口可绑定一套独立方案，热键互不冲突
- 匹配时校验进程名，避免重启后 PID 被复用导致热键误命中无关程序

**按键连发**

- 一个方案可配多组连发绑定，每组独立间隔（10–5000 ms）
- 按开关热键同时启停该组，互不干扰

**三种投递方式**

| 模式 | 行为 |
|---|---|
| 自动 | 目标在前台用 SendInput，切到后台自动改为 PostMessage 消息投递 |
| 仅前台 | 窗口不在前台就暂停 |
| 后台消息投递 | 不判断前台，持续向目标窗口投递（多开场景） |

**其它**

- 总开关（默认 F8）：按一次全部暂停并记住，再按原样恢复
- F12 急停：立即全部停止（不记忆）
- 全局键盘钩子只做虚拟键码比对，不记录、不还原字符、不落盘
- 5 套主题（热烈·朝霞 / 护眼·豆绿 / 跟随系统 / 黑暗·墨夜 / 极客·终端），支持 Per-Monitor DPI
- 配置优先存 exe 同目录；目录不可写（如 `C:\Program Files`）自动回退到 `%APPDATA%\PoisonKing\config.json`

## 使用方法

1. 打开游戏并登录，窗口保持可见（不要最小化到托盘），双击 `PoisonKing按键辅助.exe`
2. 在窗口列表里选中目标窗口 → 点输入框后直接按想用的键设定开关热键 → 添加连发绑定与间隔
3. 双击列表行或按开关热键启动，切到别的窗口连发继续；F12 随时急停

完整图文说明见 [docs/使用说明.docx](docs/使用说明.docx)，快速上手见 [docs/README_RELEASE.txt](docs/README_RELEASE.txt)。

## 从源码构建

需要 Windows + .NET Framework 4.x（Win10/11 自带），无需安装 Visual Studio：

```bat
build.bat
```

产物：`build\WinProfile.exe`（未混淆，符号可读，仅供本机调试，请勿分发）。

`tools\obfuscate.py` 为发布版符号混淆器（把类型/方法/字段名重命名为 z0..zn，提高二次修改成本，不加壳、不反调试，避免触发杀软特征）；`tools\gen_doc.py` 为使用说明 docx 生成器，构建时注入 SHA256。

## 隐私与安全

- **不联网**：源码中不存在任何网络 API 调用，无更新检查、无遥测、无回传
- **钩子只做热键比对**：`WH_KEYBOARD_LL` 回调内仅读取虚拟键码与自身配置的热键比较，不调用字符转换、不缓存按键序列、不写任何日志
- **不碰游戏**：不读写目标进程内存、不注入 DLL、不加载驱动、不修改游戏文件，仅调用 `SendInput` / `PostMessage`
- **配置不含敏感信息**：`config.json` 仅保存 PID、窗口标题、热键与间隔，无账号密码
- **权限**：清单为 `asInvoker`，不主动提权；仅当目标以管理员运行时才需要以管理员启动本程序
- **可审计**：全部源码在本仓库，欢迎自行编译或审查
