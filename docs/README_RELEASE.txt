【官方正版校验（SHA256）】
--------------------------------
为防止有人重打包捆绑恶意代码后冒名分发，请核对主程序校验值：
1. 压缩包内附 SHA256.txt，内容即本次发布主程序的官方校验值；
2. 也可自行计算核对：在解压目录执行
   certutil -hashfile "PoisonKing按键辅助.exe" SHA256
3. 结果与官方发布帖公布的值完全一致才是原版；不一致请立即删除，不要运行。
请只从作者公布的唯一官方渠道下载本软件。

【快速开始】
1. 双击 PoisonKing按键辅助.exe 即可运行，无需安装任何东西。
   （要求电脑装有 Windows 10/11 自带的 .NET Framework 4.x，没有也不用装任何其他软件）
2. 首次运行后会在 exe 同目录生成 config.json 保存配置；
   若 exe 所在目录没有写权限（如 C:\Program Files），配置会自动改存到
   %APPDATA%\PoisonKing\config.json，状态栏会有提示。
3. 如果目标游戏/程序以管理员权限运行，请右键 PoisonKing按键辅助.exe →"以管理员身份运行"。

【功能速查】
· 窗口列表：显示 PID / 标题 / 热键 / 连发绑定 / 运行状态，双击某行 = 启停该窗口
· 开关热键：点输入框后直接按下想用的键（F1-F12 等自动填入）
· 连发绑定：可加多组，每组独立间隔（毫秒），按开关热键同时启停
· 投递方式：
    自动       —— 前台用注入，切后台自动改消息投递
    仅前台     —— 窗口不在前台就暂停
    后台消息投递 —— 完全不管前台，持续向目标窗口投递
· 总开关（默认 F8）：按一次全部暂停并记住，再按原样恢复
· F12：全部急停（不记忆）
· 主题：顶部工具条可切换 热烈·朝霞 / 护眼·豆绿 / 跟随系统 / 黑暗·墨夜 / 极客·终端
  （"跟随系统"会自动检测 Windows 深浅色设置：系统深色用墨夜，浅色用豆绿）

【多屏 / 缩放】
· 支持 Per-Monitor DPI，跨不同缩放比例的显示器拖动窗口会自动适配，不再出现界面过大或模糊。

【数据安全】
· 本工具不联网、不上传任何数据；配置文件只保存在本机。
· 换电脑把 exe 拷过去即可，配置互不影响。
